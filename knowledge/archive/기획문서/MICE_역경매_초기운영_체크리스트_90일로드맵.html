01_ROADMAP

90일 로드맵 (3 Phase)

3개월을 ‘준비 → 첫 거래 → 반복·검증’의 3단계로 나눈다. 각 페이즈는 다음 페이즈로 넘어가기 위한 출구 조건(Exit Criteria)을 가진다.

Phase 1 · 준비 (Week 1–4)

주차핵심 목표주요 작업
W1정의 확정타깃·수수료율 확정, 표준 RFP 항목 설계, 비교표 템플릿 초안
W2공급 리스트업MatchGo 네트워크 기반 베뉴·호텔·연수원 30~50곳 컨택 DB 구축, 우선순위 태깅
W3공급 온보딩1차 15~20곳 접촉, ‘경쟁 입찰’ 참여 의향·조건 확보
W4수요 채널 세팅RFP 폼 배포, 파일럿 수요 3~5건 리드 확보
EXIT ▸ 입찰 의향 공급자 15곳+ 확보 그리고 파일럿 RFP 리드 3건+ 확보

Phase 2 · 첫 거래 (Week 5–8)

주차핵심 목표주요 작업
W5첫 역경매 실행RFP 1건 정규화 → 공급 3~5곳 입찰 모집
W6비교·낙찰표준 비교표 제공 → 담당자 선택 → 계약 연결
W7정산·회고수수료 청구·수금, 양측 인터뷰로 마찰점 수집
W8반복 2~3건프로세스 보정하며 추가 거래 실행
EXIT ▸ 실제 성사 거래 1건+ 그리고 수수료 1건+ 수금 완료, 첫 단위경제 실측치 확보

Phase 3 · 반복·검증 (Week 9–12)

주차핵심 목표주요 작업
W9~10거래량 확대수요 채널 2~3개로 확대, RFP 주 3~4건 목표
W11지표 집계KPI 실측, 가정값 vs 실측 비교
W12Go/No-Go게이트 판정 → 반자동화 PRD 또는 피벗 결정
EXIT ▸ 전환율 25%+ & RFP당 입찰 3+ 충족 시 GO → 반자동화 개발 착수
02_SUPPLY

공급자 온보딩 체크리스트

‘닭-달걀’ 문제 때문에 공급을 먼저 확보한다. 수요 1건이 들어와도 채울 수 있는 상태를 만드는 것이 1순위. MatchGo의 기존 호스피탈리티 파트너 관계를 첫 컨택 우선순위로 활용한다.

LIST_UP — 목표 30~50곳

  • 1차 지역·카테고리 선정(예: 수도권 연수원·비즈니스호텔 우선).
  • 각 공급자: 담당자명·연락처·수용 인원·기본 단가·비수기·결제조건 수집.
  • ‘입찰 의향 높음/중간/낮음’ 3단계 태깅으로 우선순위화.

ONBOARD — 목표 입찰 의향 15곳+

  • 가치 제안 전달: ‘비수기·빈 날짜를 채우는 적격 수요, 선불비용 0’.
  • 수수료 구조 설명(낙찰 시 10%, 첫 거래 프로모션 옵션 안내).
  • 표준 견적 양식·응답 SLA(예: 24시간 내 회신) 합의.
  • 공급자 DB에 ‘참여 확정’ 표기 + 가능한 날짜·조건 등록.
03_DEMAND

수요 확보 체크리스트

CHANNEL

  • MatchGo 기존 브랜드 고객·파트너 네트워크에 파일럿 제안(가장 빠른 첫 수요).
  • 국내 중소규모 여행사·랜드사 아웃리치(인센티브·단체 연수 대행 수요 — 호텔 객실 중심 반복 발주).
  • 지인·업계 담당자 직접 아웃리치(총무·HR·교육팀).
  • 링크드인·커뮤니티·뉴스레터로 ‘무료로 3~5개 경쟁견적’ 메시지 배포.

CONVERT

  • 표준 RFP 폼 링크 1개로 단순화(작성 5분 이내).
  • 접수 즉시 1시간 내 사람이 확인 연락(신뢰 형성).
  • ‘48시간 내 비교 견적 전달’ 약속을 명확히 고지.
04_SOP

거래 운영 SOP (1건 처리 표준 절차)

단계담당할 일목표 시간
1. RFP 접수운영자폼 응답 확인, 누락·모호 항목 보완 콜+1h
2. RFP 정규화운영자표준 항목으로 정리, 적합 공급 3~5곳 선정+3h
3. 입찰 모집운영자공급자에 RFP 전달, 응답 SLA 안내+4h
4. 견적 취합공급자표준 양식으로 가격·포함내역 제출+24h
5. 비교표 작성운영자동일 기준 1페이지 비교표 작성·전달+30h
6. 낙찰 지원담당자비교·질의·선택+48h
7. 계약 연결운영자낙찰 공급자↔담당자 연결, 조건 확정즉시
8. 정산운영자성사 확인 → 수수료 청구·수금·기록행사 후
운영 원칙
· 모든 견적은 같은 양식으로 — 비교 가능성이 핵심 가치. · 48시간 리드타임을 약속하고 지킨다(속도가 차별점). · 모든 거래의 GMV·입찰수·전환·마찰점을 거래 로그 시트에 기록 — 검증의 원천 데이터.

06_RHYTHM

주간 운영 리듬 · 검증 게이트

WEEKLY_RHYTHM

  • 월: 신규 RFP·파이프라인 점검, 이번 주 목표 설정.
  • 수: 진행 거래 상태 점검, 공급 응답 독려.
  • 금: 거래 로그 마감, KPI 업데이트, 마찰점 1개 개선 액션.

MONTHLY_GATE

지표1개월2개월3개월(합격)
RFP 접수/월≥3≥8≥15
RFP당 입찰 수≥2≥3≥3
낙찰 전환율—≥15%≥25%
성사 건수/월≥1≥3≥6
리드타임≤72h≤48h≤48h
3개월 종료 시 의사결정

GO 게이트 충족 → 반자동화 PRD 작성, 결제·폼·대시보드 개발 우선순위 결정.

PIVOT 일부 미달 → 부족한 측(수요/공급/가격)에 자원 집중 후 1개월 재측정.

STOP 수요 자체 부재 → 세그먼트·가치제안 근본 재검토.

07_RISK_CHECK

운영 리스크 빠른 점검표

  • 수요 1건당 채울 공급이 항상 3곳+ 확보돼 있는가?
  • 48시간 리드타임을 지키고 있는가? (지연 시 원인 기록)
  • 탈중개 징후(양측 직접 연락 시도)가 있는가? 가치 재강조했는가?
  • 수수료 수금 누락 건이 있는가?
  • 모든 거래가 로그에 기록됐는가? (검증 데이터 누수 방지)
  • 공급자 응답률·노쇼율이 악화되고 있지 않은가?

— 본 로드맵·기준치는 시작 가정이며, 첫 거래 데이터 확보 후 즉시 보정한다.
