## 1. 공통 규약 (모든 v2 페이지)

### 1-1. 프레임 크기 · 이름
| 종류 | 너비 | 쓰는 곳 |
|---|---|---|
| PC | 1280 | 화면 전체(머리글~푸터 또는 콘솔 셸 전체) |
| 컴팩트 | 640 | 상태가 바뀌는 블록만(머리글 생략, 위에 「앞 프레임과 같음 · 바뀐 영역만」 회색 띠) |
| 모바일 | 360 | 화면 전체, 16px 좌우 여백 |
| 모달 | 560 | 콘솔 `<dialog>` 하나(뒤 배경 없이 모달만) |

- 프레임 이름: **`화면 ID · slug · 화면 이름 · PC|컴팩트|모바일|모달`** (예 `ORG-02 · delivered · 진행 상황 화면 · PC`)
- slug는 코드 상태값 그대로. 한 상태의 변형은 `-` + 짧은 영어(`delivered-p1`, `open-error`, `modal-reject`). 코드에 상태값이 없는 화면은 이 브리프들이 정한 slug를 씀(각 브리프에 「slug 임의 지정」 표시).
- 레이어 이름 `역할/이름`: `badge/id`, `badge/tag`, `sticker/states`, `note/branch-1`, `marker/source-server`, `chip/perm-…`, `chip/notif-…`, `sticker/E-34`, `watermark/example`, `ref/spec`. 이름 없는 레이어 금지.

### 1-2. 시각 스타일 (화면 안)
- 글꼴 Noto Sans KR(영문 화면도 동일), 숫자·REF는 모노(JetBrains Mono 또는 Roboto Mono).
- 플랜 기준 색: 틸 `#128C7E`(주 버튼·링크), 네이비 `#0F1B2D`(요청 표시줄·콘솔 사이드), 배경 `#F6F8FB`, 선 `#E4E8F0`, 오류 `#EF4444`, 황색 배지 `#FFF3D6`/`#8A5A00`.
- 참고(코드 실제 토큰): `--teal #0B8F86` `--teal-deep #076E67` `--teal-bright #16B5A8` `--ink #0F1E3D` `--amber #FFC24B` `--gray #6B7794`. 플랜 색으로 그리되 차이는 의도된 것(샘플 ORG-02 3장 스타일 유지).
- 버튼: 주 버튼(채움 틸) · 보조(회색 테두리 ghost) · 위험(빨강 테두리, 콘솔 「반려」「요청 취소」「중지」「정지」「종료」「무효 처리」).

### 1-3. 주석 7종 (08 페이지 컴포넌트, 모든 프레임에 사용)
| 컴포넌트 | 위치 | 모양 · 내용 |
|---|---|---|
| `badge/id` + `badge/tag` | 프레임 왼쪽 위 바깥 | 글자 `화면 ID · slug · 상태 이름` + 태그 칩 1개 |
| `sticker/states` | 프레임 오른쪽 바깥 세로 | 그 화면의 **모든** 상태를 한 줄씩(slug + 한국어 이름), 현재만 진하게. 맨 아래 「들어오는 때 · 할 수 있는 일」 2줄 |
| `note/branch-n` | 버튼 옆 노란 메모, 점선 커넥터 | `「버튼」 → 이동 방식 · 목적지 ID · 서버 호출 · 알림 ID` |

| `ref/spec` | 프레임 아래 바깥 한 줄 | 근거: 코드 파일 · 스펙 절 (예 `build2.py TRACK_STATES · 5a ORG-02`) |

### 1-4. 용어
- 요청자 화면(ORG-*)의 배지·문구는 화면 그대로(「호텔 제안 받는 중」「제안 정리 중」「비교표 도착」「연결 완료」「종료」「진행 불가」). 설명 글(스티커·노트)은 표준 용어.
- 콘솔 상태 이름은 `admin.js STATES` 그대로: 접수됨 · 요건 확인 중 · 초대 준비 · 견적 받는 중 · 견적 정리 중 · 비교표 전달됨 · 성사 · 미성사 · 반려 · 취소됨.
- 콘솔에 남은 옛 말은 **화면 그대로 그림**: 메뉴 「견적 관리」「호텔 파트너」, 버튼 「추적 링크 복사」, 소제목 「승인 파트너 · 다낭」, 문서 제목 「견적 상세」「파트너 상세」. 해당 요소 옆에 작은 회색 칩 「코드 옛 말」.
- 호텔 화면(HTL-*)은 영어 문구 그대로.

### 1-5. 금지
- 경쟁사 캡처 금지. 실제 개인정보처럼 보이는 값 금지(휴대전화는 `010-****-5678` 모양).
- 호텔 화면에 요청자 신원(회사명·담당자·연락처·예산)을 그리지 않음. 예외: `HTL-03 · selected`의 「Organizer contact」(예시 값 + 워터마크).
